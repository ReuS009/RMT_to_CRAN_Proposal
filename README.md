## Overview of the RMT v. 2.0.0 Refit Project

The Reliability Modeling Toolkit (RMT) is an R-based library of educational tools specifically designed to execute computationally involved and challenging reliability modeling and analytical calculations based on probabilistic physics of failure (PPoF) and accelerated testing (AT) procedures, including accelerated life testing (ALT) and accelerated degradation testing (ADT).  For graduate students, educators, and industry including aerospace, manufacturing, and defense, the RMT provides a cost-free alternative to existing reliability analysis software (e.g. Reliasoft or Minitab).  However, its exclusive availability on the CRR's GitHub server limits its use to "word-of-mouth" adopters and bypasses the greater R user community by not having a CRAN package or an online documentation guide for reference.

For this project we are rectifying this oversight and performing a timely push to make the RMT available on CRAN.  Doing so will require the following:
- A full assessment of old code blocks in need of restructuring and updating
- An expansion of our testthat test driven development (TDD) tools for the RMT toolset
- and online documentation and tutorials using the pkgdown for development and upload

The outcome of these tasks will be a newly available and fully updated RMT v. 2.0.0 available not only on the existing GitHub site, but also to the greater R community on CRAN.
